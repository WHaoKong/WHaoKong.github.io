network-autosave

Open-source multi-cloud auto-save tool. 开源多网盘自动转存工具。

GitHub repository Releases AGPL-3.0 license

network-autosave is a self-hosted Flask + Vue 3 app that watches cloud-drive share links and saves new files into your own folders on a schedule. It is a non-commercial personal/open-source project.

自托管的 Flask + Vue 3 应用：定时检测网盘分享链接，把新增文件转存到自己的目录。个人开源项目，非商业用途。

Supported drives / 支持的网盘

  • Baidu Netdisk / 百度网盘
  • Quark / 夸克网盘（含每日签到领空间）
  • UC Drive / UC 网盘
  • Aliyun Drive / 阿里云盘
  • Xunlei Cloud / 迅雷云盘

What it does / 功能

  • Save share links into a chosen directory, with skip-if-already-saved
  • Global and per-task cron schedules
  • Web UI (Vue 3 + Element Plus), SSE live task logs
  • Regex filter / rename, quota alerts, 25+ notify channels
  • Docker Compose and local Python 3.10 deploy

智能去重、全局/单任务 Cron、Web 管理界面、SSE 实时日志、正则过滤与重命名、容量告警、多种通知。可用 Docker 或本地 Python 运行。

Stack

Flask · APScheduler · Vue 3 · Vite · Element Plus · Docker

Quick start

git clone https://github.com/WHaoKong/network-autosave.git

docker-compose up -d

Then open http://localhost:5000. Details are in the repository README.
